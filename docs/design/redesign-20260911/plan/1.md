## home `/`
| 섹션 | 들어갈 정보(필드) | 컴포넌트 |
|---|---|---|
| ① HeroAmount | `wealth.totalBalance` 44px · "원" · `DeltaPill asset`(현재 − 마지막 스냅샷 `yearlySnapshots.months[last].totalBalance`, %) · "지난달보다" · 기준일 모노 캡션 · blur 토글 | HeroAmount · DeltaPill · Sparkline(`months[].totalBalance` + 현재점) |
| ② 왜 늘었나 | 순저축 = `stats.monthlyIncome − monthlyExpense`(메타: 수입/지출 각 색) · 투자손익 = `portfolio.summary.totalProfit`(메타: 평가액·수익률) · 2px 기여 막대 | Section · StatRow ×2 |
| ③ 자산 구성 | `allocation.currentAllocation[]` 자산군/평가액/ratio — 도넛 대신 **행 + 비율 막대** | Section · ListRow(우측 금액 + 비율) · 링크 "전체" → /wealth |
| ④ 이번 달 | 수입 · 지출 · 저축률 3열 | StatGrid(모노 18) · 링크 → /transactions |
| ⑤ 최근 기록 | `recentTransactions.slice(0,3)` 제목/카테고리·날짜·통장/금액(income·expense·purple) | ListRow ×3 · 링크 "전체" → /transactions |
| 데스크톱 | 좌 판면 = ①+Sparkline(높이 120)+② / ③ / ⑤(5행) · 우 레일 = ④ + 지출 Top3(`byCategory`) | 2컬럼 |

- **우선 액션 1개**: `＋ 기록`(셸). 스냅샷 "기록/갱신" 은 기준일 캡션 탭으로 숨김(기능 유지).
- 상태: **빈** = 스냅샷 0 → DeltaPill 자리에 "첫 기록을 남기면 비교가 시작돼요"(dimmed, accent 링크 "지금 기록") / 거래 0 → ⑤ 헤더 + "아직 기록이 없어요" 1행 / 투자 0 → ② 투자손익 행 숨김 · **로딩** = 섹션 단위 Suspense(hero 숫자 자리 44px 스켈레톤 `--moeum-surface-2`, 행 46px 스켈레톤 3개) · **에러** = 섹션 헤더 유지 + 행 자리에 "불러오지 못했어요 · 다시 시도"(danger 아님, dimmed + accent 링크). 전체 화면 ErrorFallback 은 셸 밖 오류만.
