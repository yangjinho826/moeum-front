## invest/account/[accountId] — 투자 계좌 상세 (S6 D-1 임시본 → 정식)
| 섹션 | 정보 | 컴포넌트 |
|---|---|---|
| ① SubHeader | ← 계좌명 | 기존 |
| ② HeroAmount compact | `account.balance`(현금+평가) 28 · `DeltaPill asset`(portfolioProfitLoss · Rate) "평가손익" | HeroAmount · DeltaPill |
| ③ StatGrid | 현금 `cash` · 평가 `portfolioValuation` · 종목 N | StatGrid |
| ④ 자산 추이 | account_snapshots 이 계좌 balance 월별 + 우측 "최근 N개월 ±%" | Section · 추이선(chart-1, 축 없음) |
| ⑤ 종목 비중 | StockShares(구성 막대 + 상위 4 + 외 N + 현금) | StockShares |
| ⑥ 누적 매매수익 | `realizedPnl.summary.totalRealized · totalRate · 매도 N건` 1행 → 탭 시 시트(기존 RealizedPnlPanel) | ListRow(tall, chevron) |
| ⑦ 보유 종목 | 종목명 / 코드·시장·수량·평단 / 평가액 + 손익(▲▼ %) | Section(링크 "+ 종목 추가") · ListRow tall ×N → /invest/portfolio/[id] |
| 데스크톱 | 좌 ②③④⑦ · 우 레일 ⑤⑥ | 2컬럼 |
- **우선 액션 1개**: 종목 추가(섹션 링크). 매매는 종목 상세에서.
- 상태: **빈** = 종목 0 → ⑤ 숨김·⑦ "보유 종목이 없어요 + 종목 추가" / 박제 <2 → ④ 숨김 / 매도 0 → ⑥ 숨김 · **로딩** = hero 28 스켈레톤 + 행 3 · **에러** = 섹션 인라인 "불러오지 못했어요 · 다시 시도".
