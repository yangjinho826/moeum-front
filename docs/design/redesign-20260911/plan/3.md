# 배치3 계획표 — account/[accountId] · account/new · account/[accountId]/edit · 매매 시트(폼 일괄) (2026-09-12)

가설 = 배치1 pick **A(결과 하나) + C(추이가 주인공)** 확장(재생성 없음). 토큰·컴포넌트 = DESIGN.md §2~§5 + 배치1·2 공용(HeroAmount compact · DeltaPill · StatGrid · Section · ListRow · TrendLine · SubHeader · AccentLink · SectionSkeleton · SectionBoundary · EmptyText · FormSheet · FormActions). 데이터는 **지금 API 가 주는 것만**. 코드 근거 = account-section · account-report-section · account/form · trade-form · transaction/form · form-actions 감사.

## 결정 (사용자, 2026-09-12)
- **/account 목록 → /wealth 리다이렉트.** 들어오는 링크 0(설정 "통장" 행 = /wealth, 자산 화면에 같은 통장 섹션). 폼 페이지 모드 저장·삭제 후 이동도 /wealth. `account-section` · `account/components/table` · `use-search` 는 참조 0 이 되면 삭제 여부를 따로 묻는다.
- **통장 상세 월별 수입·지출 막대 제거.** 이번 달 = StatGrid, 달마다 증감 = 잔액 추이, 지난달 상세 = 거래 내역이 이미 말한다 — 차트 둘이면 "추이가 주인공"(C)이 흐려진다. `monthlyFlows` 는 StatGrid(이번 달)·hero 델타(지난달 잔액)에만 쓴다.
