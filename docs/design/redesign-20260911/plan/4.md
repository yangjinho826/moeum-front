# 배치4 계획표 — category · category/new · category/[categoryId] · fixed (2026-09-12)

가설 = 배치1 pick **A(결과 하나) + C(추이가 주인공)** 확장(재생성 없음). 관리 화면이라 "결과 하나" = 고정지출은 이번 달 합계, 카테고리는 목록 자체. 토큰·컴포넌트 = DESIGN.md §2~§5 + 배치1~3 공용(SubHeader · AccentLink · HeroAmount compact · Section · ListRow · StatGrid · MonthPicker · SectionSkeleton · SectionBoundary · FormSheet · FormActions · ColorPicker · IconPicker). 데이터는 **지금 API 가 주는 것만**. 코드 근거 = category-section · category/table · category/form · fixed-section · fixed/table 감사.

## 감사에서 나온 것
- 카테고리·고정지출 목록 = `Card` + `IconBox`(아이콘 박스) + 분류 `Badge`(지출 = `danger` — 에러색을 분류에 씀). DESIGN §5·§8(카드 없음 · 아이콘 박스 없음) 위반.
- 헤더 = `Title order=3` + "＋ 추가" pill 버튼 — 다른 하위 화면(통장 상세 "수정")은 SubHeader + AccentLink.
- 고정지출 행 금액 = **이번 달 사용액만**. 매달 예정 금액(`amount`)이 목록 어디에도 없다. 월 합계는 Card 안 `size="lg"` + 하드코딩 "고정지출" 문구(i18n 누락).
- `/category` · `/fixed` 에서 **하단 탭이 아무것도 활성 아님**(내정보 탭 match = `/settings` 만). 진입은 내정보 "관리" 행.
- 문구 불일치: 목록 제목 "고정 지출" vs 내정보·통장 상세 "고정지출".
- `IconBox` 는 이 두 목록에서만 쓰인다 → 아이콘 박스를 걷으면 사용자가 고른 아이콘이 앱 어디에도 안 보인다(아래 결정 1).

## 결정 필요 (캔버스에서 고름)
1. **카테고리 목록 형태** — **A(추천) 섹션 그룹 + 아이콘 글리프**: "지출 N" · "수입 N" 두 섹션, 행 앞 18px 아이콘(카테고리 색, 박스 없음). 필터 탭 없이 한 화면에 전부(19개 = 1페이지 30 안). 분류 배지 제거. / **B** 밑줄 칩 필터(전체 · 지출 · 수입, 거래 화면과 같은 칩) + 제목 앞 6px 점(DESIGN 규칙 그대로). 아이콘은 폼에서만 보임.
2. 고정지출 행에도 같은 선택을 따른다(A = 아이콘 글리프 / B = 점).
