# 배치5 계획표 — fixed/new · fixed/[fixedId] · household · household/new (2026-09-13)

가설 = 배치1 pick **A(결과 하나) + C** 확장(재생성 없음). 관리·폼 화면이라 새 룩 없이 배치3·4 문법 그대로. 토큰·컴포넌트 = DESIGN.md §2~§5 + 배치1~4 공용(SubHeader · AccentLink · Section · ListRow(lead) · FormSheet · FormActions · ColorPicker · IconPicker · FormGuide · SegmentedControl 44 · EmptyText · SectionSkeleton). 데이터는 **백엔드 스키마에서 확인한 필드만**(배치4 룰 구멍 — `moeum-back/app/domain/{fixed,household}/schema.py` 대조 완료).

## 감사에서 나온 것 (코드 + 백엔드 대조)
- **고정지출 폼 "금액" = 유령 필드** — 백엔드 FixedCreate/Update/Response 에 금액 없음. 입력해도 저장 안 되고 수정 시트에선 빈칸(배치4 H-404).
- **고정지출 카테고리 연결 입력 없음** — 백엔드는 `category_id`(같은 가계부 활성 카테고리 검증)를 받는데 폼에 필드가 없어 목록 메타에 카테고리가 안 뜬다(uitest 14개 전부 "매월 1일"만).
- **고정지출 보관(`is_archived`) UI 없음** — 백엔드: 보관하면 거래 기록 선택지(form-options)에서 빠지고, 과거 거래·목록엔 남음. 목록도 보관/활성 구분 없음.
- 결제일 = 표시·정렬용(백엔드에서 자동 생성·알림 없음). 삭제 = soft delete, 과거 거래엔 고정지출 이름이 남음(`FixedRepository.find_by_ids` 상태 필터 없음).
- **가계부 목록 = Card + 검색 폼(아무것도 거르지 않음 — 주석 "현재 표시만") + "멤버 0명"** — 백엔드 HouseholdResponse 에 `memberCount` 없음(항상 0 표시). 응답엔 `role`(OWNER/MEMBER) 있음.
- 가계부 수정·삭제 = **소유자만**(`HOUSEHOLD_NOT_OWNER`) — 지금 목록은 멤버 행도 수정 시트를 연다(저장·삭제 시 403 토스트).
- 가계부 폼: 통화 TextInput 자유 입력(3자) — 앱 전체가 원 단위 표시라 바꿔도 아무 데도 반영 안 됨. 설명 Textarea `value=null` 콘솔 경고(배치3 H-307). 시작일 DateInput `YYYY-MM-DD`(다른 폼은 `YYYY.MM.DD`, 배치3 F-308). 간격 `sm` 8.
- 가계부 전환기(household-switcher)는 셸 소속(배치1) — 이번 범위 밖, `sage/terracotta` 직접 참조는 보류로만 적는다.

## 결정 필요 (캔버스에서 고름)
1. **고정지출 금액** — **A(추천) 폼에서 제거**: 백엔드 그대로, "예정 합계" 없이 사용액만(배치4 목록과 일치). / **B** 백엔드에 금액 컬럼 추가(마이그레이션 — 실행 전 따로 확인) → 폼 금액 + 목록 "예정" · 미기록 판단 강화. 브리프 "기능 추가 없음"이라 A 추천.
2. **가계부 통화** — **A(추천) 폼에서 제거**(생성 기본 KRW, 백엔드 그대로). / **B** 읽기 전용 행 "통화 KRW".
3. **가계부 목록 멤버 행** — **A(추천) 소유자 행만 수정(chevron), 멤버 행은 메타 "멤버"·chevron 없음·누를 수 없음** / **B** 모든 행 탭 = 그 가계부로 전환(수정은 행 끝 "수정" 링크, 소유자만).
