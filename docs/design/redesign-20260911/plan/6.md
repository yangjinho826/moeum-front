# 배치6 계획표 — household/[householdId] · household/[householdId]/members · login · register (+ 셸 가계부 전환기) (2026-09-13)

가설 = 배치1 pick **A(결과 하나) + C** 확장(재생성 없음). 관리·게스트 화면이라 새 룩 없이 배치3~5 문법 그대로. 토큰·컴포넌트 = DESIGN.md §2~§5 + 배치1~5 공용(SubHeader · AccentLink · Section · ListRow(valueText) · FormSheet · FormGuide · EmptyText · Hairline). 데이터는 **백엔드 스키마에서 확인한 필드만**(`moeum-back/app/domain/{household,user,auth}` 대조 완료).
진행 = 사용자 "전체 총괄" 위임(2026-09-13) — 캔버스(Claude Design) ⏭, Figma 가 시안 · pick 은 추천안.

## 감사에서 나온 것 (코드 + 백엔드 대조)
- **멤버 관리 = Card 2장 + 원형 아바타(info-0) + 왕관 `#F59E0B` + 휴지통 `#EF4444` hex** — DESIGN §1 카드 0장 · §8 hex 금지 위반. 주 진입은 내정보 → 멤버 관리 시트(MembersSheet), 라우트는 fallback.
- 멤버 응답 = `userName · userEmail · role · joinedAt`. 초대 = 이메일로 사용자 검색 → 추가(소유자만, 미가입이면 CM004). 내보내기 = 소유자만 · 소유자 본인은 불가(`HOUSEHOLD_OWNER_CANNOT_LEAVE`) · soft delete(그 사람이 남긴 기록은 남음). 멤버도 모든 가계부 데이터 조회·기록 가능(`get_current_household` = 멤버십만 확인).
- 내정보 "멤버 관리" 행 메타가 `memberCount` — HouseholdResponse 에 없는 필드라 항상 안 보임(배치5 유령 필드와 같은 것). 타입에서도 제거.
- **로그인 = 그라데이션 hero + 세리프 흔적 워드마크 + 그림자 카드 시트(`TOKEN.card` · `rgba(120,100,70,.1)`)** · 게스트 레이아웃 `linear-gradient(#F3E6DA → #FAF6EF)` hex — §1 그라데이션·그림자·카드 금지, 다크 모드에서 크림 그라데이션이 그대로 뜬다.
- 회원가입 진입 링크는 **베타 차단**(37348a0 "회원가입 진입점 — 베타 단계에서 차단") → 로그인에 링크를 다시 넣지 않는다. 가입 화면은 URL 직접 진입만.
- 가입 비밀번호 규칙(백엔드 `_check_password`: 8~64자 · 영문 1+ · 숫자 1+)이 화면에 안 보이고 클라이언트 검증도 "비어 있지 않음"뿐 → 제출해야 서버 에러(US004)로 알게 된다.
- 가입 제목 `Title` 기본 크기(28?) · 버튼 radius md/xl 혼재 · 로그인 인풋 `size="md"` 직접 지정(테마 기본과 같음).
- **가계부 전환기(셸)** = 자체 Drawer(radius 24 · 핸들 gray-3) + 44 아이콘 박스(sage-0/terracotta-0) + 왕관 + 선택 원형 체크 + `memberCount` — §5 시트 규칙·§2-3 "아이콘 박스를 물들이지 않는다" 위반. 가계부 목록(배치5 73:517)과 행 문법이 다르다.
- household/[householdId] = 가계부 수정 페이지 모드(HouseholdFormSection, 배치5에서 좌 폼 · 우 도움말 완료) — 이번엔 확인·촬영만.

## 결정 (위임 — 추천안)
1. **멤버 행 내보내기** — **A(추천) 행 끝 "내보내기" 글자 버튼(subtle danger 13/600, 히트 44)** → 확인 모달 / B 행 탭 → 확인 모달(발견성 낮음). 소유자가 볼 때 소유자 외 행에만.
2. **초대 위치** — **A(추천) 목록 아래 "멤버 초대" 섹션**(정보 먼저, 행동은 폼처럼 아래) / B 맨 위(이전 순서).
3. **로그인 레이아웃** — **A(추천) 한 칼럼 명세서: 로고 40 → 워드마크 28/800 accent → 태그라인 → 필드 → 버튼 52**, 카드·그림자·그라데이션 0 / B 하단 시트 유지(색만 교체).
4. **전환기** — **A 셸 옵션 A(사용자 2026-09-13 "A로가")**: FormSheet + ListRow(가계부 목록과 같은 행) · 지금 쓰는 가계부 "사용 중" · 아래 "＋ 새 가계부" · "가계부 관리" 링크.
